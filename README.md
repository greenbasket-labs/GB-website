# Green Basket Global Limited — Public Website

A lightweight, responsive company landing page built from plain HTML and CSS.

## Goals
- Public company introduction and services
- School management software
- School website design and development
- Technical support
- Direct WhatsApp, phone, and email contact

## Local preview
Open `index.html` in a browser. No build step, package manager, or database is required.

This is a standalone public website. It does not contain or replace any existing Green Basket or SkulGo application.

## Deployment
Deployment and custom-domain configuration will be decided only after the local version has been reviewed and approved.
